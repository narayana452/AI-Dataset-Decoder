AI Dataset One-Hot Encoder using Decoder Logic

EC2201 · Digital Logic · Decoder-based encoding of categorical data

Problem Statement

Design a software solution for the real-world scenario "AI Dataset One-Hot Encoder using Decoder Logic", using the specified digital-system concept and reproducible synthetic data.

The solution must demonstrate the relevant EC2201 syllabus concept and provide testable inputs, outputs and results.

Software Solution

A practical software/simulation solution: a working converter / encoder / decoder with test cases and a validation report.

  1. Create category codes
  2. Implement decoder
  3. Generate one-hot vectors
  4. Validate
  5. Compare with standard encoding

Tools: Python, Jupyter, NumPy, Matplotlib, Logisim-evolution (optional)

Assumptions and Input Format

  • Categories are separated by commas or new lines; leading/trailing spaces are removed.
  • Category names are case-sensitive. Duplicates are merged (first occurrence wins).
  • Between 1 and 64 unique categories are supported.
  • Category i (order of first appearance) gets the binary code of i using n = max(1, ⌈log₂k⌉) bits.
  • A decoder with n inputs has 2ⁿ outputs. Only the first k outputs form the one-hot vector; the rest are unused lines.
  • Dataset values must be one of the defined categories, otherwise the row is reported as an error.
